# OUTRUN — кассета для DECK

Синтвейв / ретровейв / чиллвейв / дарксинт. Ночная трасса, неоновая сетка, пады как у Juno, барабаны 80-х с гейтованным ревером.
Кассета реализует API из `DECK_SPEC.md` (раздел 12). Папка: `tapes/outrun/`.
Главное требование: **звук прям синтвейвовский из коробки**, без долгой настройки.

---

| # | Дорожка | Движок | Секвенсор по умолчанию | Эффект |
|---|---|---|---|---|
| 1 | DRUMS | `KIT84` | STEP | GATEVERB на снейр/клэп/томы |
| 2 | BASS | `MONO` | STEP | DRIVE |
| 3 | PAD | `JUNO` | LIVE (дорожка гармонии для SPLIT) | CHORUS |
| 4 | KEYS | `PLUCK` | ARP | ECHO-посыл |
| 5 | LEAD | `HERO` | LIVE | ECHO 1/8. |
| 6 | FX | `TEXTURE` | LIVE | REVERB-посыл |

Движков в кассете 9: `KIT84`, `MONO`, `JUNO`, `PLUCK`, `DX`, `HERO`, `TEXTURE`, `PHASE`, `ARCADE`.

Любую дорожку можно переключить на любой движок (например, 4 → `DX`, 6 → второй `HERO`).

## 2. Движки

Бюджет CPU — проверить бенчмарком. Ориентир для полного трека: KIT84 ≈ 6 голосов, MONO 1, JUNO 5–6, PLUCK 4, HERO 1 (3 пилы), TEXTURE 2. При нехватке — сначала режутся хвосты PLUCK и TEXTURE, потом слои, потом DRIFT.

### 2.0 Общие правила звука (как у OP-1, но под нас)
- **У каждого движка ровно 3 главных параметра + MACRO.** 3 главных — на 3 цветных энкодерах на вкладке ENGINE страницы SOUND, нарисованы картинками (8.3). MACRO — одна «волшебная» ручка пресета, крутит сразу несколько вещей; на странице PLAY энкодер 2 = MACRO текущей дорожки (для живой игры).
- **Вкладки SOUND (как 4 страницы OP-1):** `ENGINE` (3 главных) → `ENV` (ATTACK / DECAY-SUSTAIN / RELEASE) → `FX` (TYPE / AMOUNT / PARAM) → `MOD` (TYPE / DEPTH / RATE). Остальные параметры движка (если есть) — внутри пресета, руками не крутятся. Меньше ручек = быстрее звук.
- **«Аналог»:** в JUNO, HERO, MONO, PLUCK каждый голос чуть расстроен (±3–6 центов, свой на голос), медленно плавает (дрейф 0.1–0.3 Гц), фаза осцилляторов при нажатии случайная, срез фильтра на голос ±2 %. Это и есть тёплый Juno-звук. Параметр кассеты `DRIFT` (по умолчанию 40 %).
- **Слои:** опционально у JUNO/DX — второй пресет поверх (пад + колокол), громкость слоя на MACRO-странице. Ест вдвое голосов — по умолчанию выключено.

| Движок | Главные 3 (энк. 1 / 2 / 3) | MACRO (что крутит) |
|---|---|---|
| `KIT84` | TUNE / DECAY / TONE — выбранной полосы | `GATE`: гейт-ревер + punch |
| `MONO` | CUTOFF / ENV / GLIDE | `GROWL`: drive + резонанс + огибающая |
| `JUNO` | CUTOFF / CHORUS / RELEASE | `SUNSET`: фильтр + хорус + посыл в ревер |
| `PLUCK` | TONE / DECAY / ECHO | `SPARK`: FM-звон атаки + яркость |
| `DX` | TINE / DECAY / DETUNE | `DREAM`: хорус + мягкость + длинный хвост |
| `HERO` | CUTOFF / DETUNE / GLIDE | `SCREAM`: резонанс + drive + вибрато |
| `TEXTURE` | LENGTH / TONE / RISE | `EPIC`: длина + ревер |
| `PHASE` | SHAPE / SWEEP / WAVE | `GLASS`: искажение фазы + атака |
| `ARCADE` | WAVE / ARP / BITS | `8BIT`: биты + частота дискретизации |

### 2.1 `KIT84` — драм-машина 80-х (DRUM, синтез без сэмплов)
8 голосов-полос:
| Полоса | Синтез | Параметры |
|---|---|---|
| KICK | синус + падение питча + клик | TUNE, DECAY, PUNCH |
| SNARE | тон 180–220 Гц + шум (ВЧФ/полоса) | TUNE, SNAPPY, DECAY |
| CLAP | 3–4 шумовых всплеска + хвост | SPREAD, DECAY |
| CHH | 6 квадратов (как у 808) → полосовой + ВЧФ, короткий | TONE, DECAY |
| OHH | то же, длинный; глушится CHH | TONE, DECAY |
| TOM L / TOM H | синус с сильным падением питча («электротомы») | TUNE, SWEEP |
| PERC | cowbell / rim / shaker / crash — по киту | TUNE, DECAY |
- Посыл в **GATEVERB**: плотный короткий ревер + резкий гейт 150–400 мс. Параметры SIZE, GATE, MIX. Это главная фишка снейра.
- Киты (пресеты): `1984` `ARCADE` `GATED` `TAPE` `METAL` `SOFT` `CHROME` `NOIR` `MIAMI` `ROBO` `DUST` `BIG ROOM`.

### 2.2 `MONO` — бас (MONO)
- SAW + PULSE (PWM) + SUB, 24 дБ ФНЧ с резонансом и огибающей, насыщение, глайд.
- **Режимы игры** (параметр MODE, работают в любом секвенсоре): `NOTE`, `PUMP` (8-е по корню), `OCTAVE` (октавный 16-й), `GALLOP` (8 + 16 + 16), `ROOT5` (корень–квинта).
- Пресеты: `PUMPER` `RUBBER` `GROWL` `SUB` `PLUCK` `ACID` `FAT` `NIGHT` `OCTAVER` `SOFT` `BITE` `DEEP`.

### 2.3 `JUNO` — полифонический пад (POLY)
- На голос: DCO (SAW + PULSE с PWM + SUB + шум) → ФНЧ с резонансом → ADSR; LFO на PWM/питч/фильтр.
- **BBD-хорус I / II / I+II** — встроен в движок (а не только слотом эффекта): 1–2 модулируемые линии задержки с лёгким срезом верха. Без него не будет того звука.
- Детюн голосов «аналоговый» (каждый голос чуть разный, плавает).
- Пресеты: `SUNSET` `NEON` `VHS PAD` `BRASS` `STRINGS` `GLASS` `CHOIR` `CRYSTAL` `WARM` `SWELL` `DARK` `HOPE`.

### 2.4 `PLUCK` — арп и клавиши (POLY)
- Короткий: пила/квадрат → фильтр с быстрой огибающей, лёгкий FM-«звон» атаки.
- Пресеты: `DROPS` `SPARK` `BELL` `KEYS` `MARIMBA` `HARP` `GLASS` `CHIP` `BUBBLE` `NIGHT` `SOFT` `STAB`.

### 2.5 `DX` — FM-электропиано и колокола (POLY)
- 2–4-оп FM, классика 80-х/чиллвейва: E.PIANO, BELLS, BASS-FM, «стеклянные» клавиши. Можно взять за основу FM-пиано из OVERWORLD.
- Пресеты: `E.PIANO` `TINE` `BELLS` `GLASS EP` `CELESTA` `FM BASS` `VIBES` `CHIME` `TOYBOX` `SLAP` `DREAM EP` `HOLLOW`.

### 2.6 `HERO` — лид (MONO)
- 3 детюненных пилы (суперсо-лайт) или PULSE; ФНЧ; **портаменто**; **задержанное вибрато** (через 300 мс); унисон-ширина.
- Пресеты: `HERO` `SAX-ISH` `WHISTLE` `SCREAM` `SOFT` `SQUARE` `GLIDE` `LASER` `FLUTE` `SYNC` `BRASS LD` `GHOST`.

### 2.7 `TEXTURE` — звуки-события и фактуры (POLY, 2 голоса)
Клавиша = событие, длина ноты = длина события.
- **RISER** (шум с открывающимся фильтром + питч вверх), **DOWNLIFTER**, **SWEEP**, **IMPACT** (удар + хвост), **CHOIR** (формантный «ааа/ооо»), **WIND**, **RAIN**, **TAPE HISS**, **RADIO** (шум эфира), **CITY** (гул), **LASER ZAP**, **REVERSE CYMBAL**.
- Это и есть «FX в пресетах»: пресеты движка = эти события.

### 2.8 `PHASE` — фазовые искажения, как Casio CZ (POLY)
- Синус, форма которого «ломается» фазовым искажением: SHAPE = глубина, SWEEP = как быстро искажение затухает после удара (огибающая на SHAPE), WAVE = тип (SAW / SQUARE / PULSE / RESO-1 / RESO-2 — резонансные формы CZ).
- Звенящие стеклянные клавиши, «резиновый» бас, 80-е как они есть. Дешёвый по CPU (таблица + одна огибающая).
- Пресеты: `CZ GLASS` `RUBBER` `RESO` `BRASSY` `HOLLOW` `CHIME` `CZ BASS` `PLUCKY` `ORGAN` `SOFT` `METAL` `NIGHT`.

### 2.9 `ARCADE` — 8-бит (POLY, 3 голоса + шум)
- Как звукочип приставки: пульс 12.5 / 25 / 50 %, треугольник, шумовой канал. WAVE = форма, ARP = быстрый «чип-арп» аккорда в одном голосе (выкл / 1/32 / 1/64), BITS = разрядность 8→2 бит + понижение частоты.
- Для MOOD CYBER и стиля ARCADE; на барабанах тоже работает (шум).
- Пресеты: `CHIP LEAD` `CHIP ARP` `TRIANGLE BASS` `NOISE HAT` `POWER UP` `COIN` `BOSS` `8BIT PAD` `SQUARE` `RETRO` `GLITCH` `LASER`.

## 3. Эффекты кассеты

**Слоты дорожки (вкладка FX, как эффекты OP-1):** `CHORUS` (BBD), `TAPE` (wow/flutter + сатурация), `PHASER`, `BITCRUSH`, `DRIVE`, `FILTER` (ФНЧ/ФВЧ с резонансом), `GATEVERB`, а также по мотивам OP-1:
- `SPRING` — пружинный ревер (дешёвый: 2–3 аллпасса + дисперсия, «бойнг» на транзиентах);
- `PUNCH` — компрессор с перегрузом, для барабанов и баса;
- `NITRO` — фильтр с автоматической огибающей / от громкости, для подъёмов;
- `PHONE` — «звук из телефона»: полоса 300–3000 Гц + лёгкий клип, для брейков.
У каждого эффекта ровно 3 ручки: TYPE / AMOUNT / PARAM.
**Посылы DECK:** ECHO (синхро, 1/8., 1/4, 1/8, пинг-понг, фидбек, тёмный тон); REVERB — типы `HALL`, `PLATE`, `SPACE` (длинный, мерцающий).
**Мастер:**
- **SIDECHAIN** — бочка «качает» выбранные дорожки (по умолчанию PAD, BASS, KEYS). Параметры AMOUNT, RELEASE. **Обязательно, это суть жанра.**
- **VHS** — одна ручка: плавание питча, лёгкое насыщение, срез верха, шип, редкие «дропауты». 0 = чисто, 100 = убитая кассета (чиллвейв).
- **SUNSET** — макро: открывает фильтры, добавляет хорус и ревер на всё.
- Мягкий клиппер.

## 4. Аккорды и гармония кассеты

### 4.1 «Острые» аккорды (4 последние чёрные клавиши, DECK 4.4)
- В миноре: **IV** (мажорная субдоминанта, дорийская краска), **V** (мажорная доминанта), **♭II** (неаполитанский, дарк), **I** (мажорная тоника — «пикардия», надежда).
- В мажоре: **♭VI**, **♭VII** (заимствованные из минора — главная ностальгия синтвейва), **iv** (минорная субдоминанта), **II** (мажорная, «кинематографичная»).
- Для остальных ладов — по аналогии, ближайший набор.

### 4.2 Пресеты аккордов (быстрый выбор типа + voicing)
`OUTRUN` (MIN9/MAJ7, OPEN), `MIAMI` (MAJ7/ADD9, SPREAD), `DARK` (MIN + SUS2, POWER), `CHILL` (MAJ9/MIN11, DROP2), `ARENA` (5 + OCT, POWER), `DREAM` (ADD9 + SUS2, SPREAD).

### 4.3 Прогрессии для DRIVE (если аккордов нет)
- Минор: `i–VI–III–VII`, `i–VII–VI–VII`, `i–iv–VI–V`, `VI–VII–i–i`, `i–III–VII–VI`.
- Мажор: `I–V–vi–IV`, `vi–IV–I–V`, `I–♭VII–IV–I`, `IV–V–iii–vi`.
- Дорийский: `i–IV–i–IV`, `i–VII–IV–i`.

## 8. Тема и сцены

### 8.0 Сцены — готовые картинки (ГЛАВНОЕ)
Фоны сцен — **готовые картинки** из `scenes/` (векторные иллюстрации, прогнанные через пикселизатор). Код сцену **не рисует**, а **оживляет поверх картинки**. Нарисованные кодом ROAD/GRID из прошлых версий ТЗ — отменены.

**8 сцен = 8 меток частей трека** (метка части → сцена; переназначается на странице ROAD):

| Сцена | Часть | Где аккорд | Эквалайзер (6 дорожек) | Что ещё живёт |
|---|---|---|---|---|
| `city` — окно, дождь, синт на подоконнике | INTRO | билборд в центре | окна небоскрёбов | дождь (гуще на хетах); **клавиши нарисованного синта подсвечиваются нотами, которые ты играешь**; дисплей синта и огонёк кассеты на бочку |
| `drivein` — кинотеатр под открытым небом | PRE | **на киноэкране как титр фильма** (стиль `film`: тёмные буквы на светлом экране, мерцание проектора) | стоп-сигналы 6 машин | звёзды от KEYS, пальмы качаются раз в такт, луч проектора |
| `road` — трасса, жёлтая машина | VERSE | **3 табло**: часть / аккорд / следующий аккорд | фонари (пульс на бочке) | разметка бежит на зрителя (скорость = темп), машина подпрыгивает на бочке, стоп-сигналы на снейре |
| `grid` — неоновая сетка | CHORUS | экран над солнцем | **полосы солнца** (6 полос снизу вверх) | сетка бежит к зрителю (color cycling), вспышка на бочке, звёзды от KEYS |
| `arcade` — зал игровых автоматов | DROP | неоновая рамка на дальней стене | экраны 6 автоматов | шахматный пол «вспыхивает» на бочке, на экранах мелькают спрайтики на хетах |
| `vhsroom` — комната 80-х, телевизор, музыкальный центр | BRIDGE | на экране телевизора (свечение кинескопа + бегущая строка развёртки) | **настоящий графический эквалайзер на музыкальном центре** (панель на 6 столбиков) | колонки качают на басу, дисплей видика мигает, окна города за окном мигают от KEYS |
| `diner` — придорожная закусочная | BREAK | вывеска на столбе (аккорд) + вывеска на крыше (название части) | окна закусочной | стоп-сигналы машины на снейре, раз в 8 тактов по дороге проезжают фары |
| `sunrise` — пирс на рассвете | OUTRO | табличка у пирса | гребни волн | солнце медленно встаёт за время OUTRO, чайки летят (спрайты), блик |

Смена сцены — VHS-переход 6–8 кадров (полосы помех + сдвиг строк) на границе части.

**Ассеты** (`scenes/`):
- `<name>_240.png` — 240×240, 64 цвета, картинка по ширине экрана, сверху/снизу тёмные поля под шапку и подвал. `<name>_120.png` — 120×120 (выводить ×2), если 240 не влезают по памяти.
- `src/<name>.jpg` — исходники 1024×1024. `make_scenes.py <src> <out>` — пикселизатор + генерация `zones.json` + `preview_sheet.png`. **Координаты зон задаются в нём, в пикселях исходника** — чтобы заменить картинку, кладёшь новый `src/<name>.jpg`, при необходимости правишь координаты, перезапускаешь.
- `zones.json` (координаты экрана 240×240): `parts`, `image_y/h`, `signs[]` (`role`: `chord` / `part` / `next`, `rect`, `style`: `neon` или `film`), `eq` (`mode`: `windows` / `sun_stripes` / `waves` / `lamps` / `bars` / `car_lights` / `screens`, `region` — прямоугольник или список из 6 прямоугольников = 6 дорожек), `hot` (точки и прямоугольники для анимаций: машина, фонари, разметка, синт, бумбокс, чайки и т.д.), `anim` (словами — что анимировать).
- `reference/` — **как это должно выглядеть и работать**: `road_anim_reference.gif` (левая половина — эта трасса), `city_anim_reference.gif`, и скрипты `anim_*_reference.py`, которыми эти GIF сделаны (логика окон-эквалайзера, бегущей разметки, неона, дождя — переносить на C).
- Сделай `tools/scene_pack.py`: PNG → индексная картинка (палитра ≤ 64 цвета, RLE/LZ4 по строкам) → бинарь во флеш; + `zones.json` → C-структуры. Посчитай, влезают ли 8 сцен в 240; если нет — 120×2 (выглядит почти так же, проверено).

**Как анимировать (обязательные техники, экран медленный):**
1. **Dirty rects** — перерисовываются только изменившиеся участки; под спрайтом фон восстанавливается из картинки.
2. **Аккорд на вывеске** — неон пиксельным шрифтом прошивки, 2 цвета свечения, иногда мигает как живая лампа; смена аккорда — моргание.
   **Текст НИКОГДА не выходит за рамку.** Отступ ≥ 10 % ширины. Самый крупный шрифт (L → M → T), который влезает; не влезает — сократить (`MAJ9`→`M9`, `MIN11`→`M11`, `7SUS4`→`7S4`, `ADD9`→`+9`); не влезает и так — корень + цифра. Правило для **всех** надписей UI. Тест: все аккорды × все вывески всех сцен → ни одного пикселя текста вне `rect`.
3. **Окна-эквалайзер** — при упаковке сцены найти яркие тёплые/голубые пиксели окон в `eq.region` (см. `anim_city_reference.py`), разбить по x на 6 колонок = 6 дорожек, по высоте = уровень. Негорящее окно ×0.3, верхнее горящее — белая вспышка. Маска окон хранится в паке.
4. **Color cycling** (почти бесплатно): блик на воде, сетка `grid`, полосы солнца — сдвиг цветов палитры, а не пикселей.
5. **Спрайты**: дождь, чайки, огоньки, бумбокс, голова парня. Маленькие, рисуются кодом или 2–4-кадровые мини-спрайты.
6. Бюджет: анимация сцены ≤ 15 % CPU-времени UI; при перегрузе звука сцена замирает (звук важнее картинки).

### 8.1 Палитра UI
Неон: розовый `#FF2A8A`, фиолетовый `#7A2BFF`, бирюзовый `#00E5FF`, оранжевый `#FF8A00`, жёлтый `#FFD23F`. Цвета энкодеров DECK: **розовый / бирюзовый / оранжевый**. Шапка/подвал — тёмные `#05021A` с полупрозрачностью поверх сцены.

### 8.2 VHS-слой (лёгкий, ТОЛЬКО на странице PLAY поверх сцены; остальные страницы — минимализм OP-1, DECK_SPEC 9.1)
Сканлайны (каждая 3-я строка ×0.8), лёгкое цветовое расслоение текста (розовая/голубая тень ±1 px), редкая полоса трекинга (раз в несколько секунд проезжает тонкая светлая полоса), затемнение по углам. **Лёгкий** — не мешает читать. Сканлайны и виньетка — предрассчитанная маска, не считать каждый кадр.

### 8.3 Рисунки параметров (страница SOUND)
Каждый параметр нарисован (как у OP-1), рисунок меняется вместе со значением:
- **CUTOFF** — солнце садится за горизонт при закрытии; **RES** — яркость ободка солнца.
- **CHORUS** — две волны расходятся. **REVERB** — туннель в глубину. **ECHO** — точка и её затухающие копии.
- **ENV (ATK/DEC/REL)** — силуэт горы: склон = атака, спуск = релиз.
- **DETUNE** — две машины рядом, разъезжаются. **GLIDE** — дорога-змейка.
- **DRIVE** — тахометр, стрелка уходит в красную зону. **VHS** — телевизор с помехами.
- **SWING (LFO)** — качели, **DICE** — кубик, **PEDAL** — педаль газа, **FOLLOW** — два сердечных ритма на цепочке.
- Иконки рисует Claude Code сам пиксель-артом (16–24 px, 2 состояния min/max, промежуточные — интерполяция/смешивание), стиль — как в `ui_concepts/Sound.dc.html`.

### 8.4 Сплэш
Надпись `OUTRUN` хромом с бликом поверх сцены `grid`, короткий бегущий блик, 1.5 с. Затем VHS-плашка `PLAY ▶`.

## 9. Демо-проект
Прошивка при первом старте содержит готовый трек `DEMO 84` (SUNSET, 100 BPM, ля минор):
- Части: `INTRO` (PAD + KEYS-арп, 8 т.), `VERSE` (+ DRUMS HALFTIME + BASS PUMP, 16 т.), `CHORUS` (DRIVE-бит, OCTAVE-бас, LEAD-мелодия, 16 т.), `BRIDGE` (только PAD + TEXTURE CHOIR, 8 т.), `OUTRO` (8 т., DROP барабанов).
- Трасса: INTRO → VERSE → CHORUS → BRIDGE → CHORUS → OUTRO, с RISER перед CHORUS и TAPESTOP в конце.
- Прогрессия `i–VI–III–VII` (Am–F–C–G), в CHORUS аккорды MIN9/MAJ7.
- Нужен как демонстрация и как регрессионный тест (WAV-рендер всей песни + экспорт `.mid`).
