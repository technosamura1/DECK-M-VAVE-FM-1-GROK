Пользователь: Даниил, музыкант-любитель, не программист. Общайся по-русски, коротко, по-простому. Показывай результат картинками (PNG/GIF) и звуком (WAV), а не кодом.

## 2. Принятые решения (не обсуждать, делать)

**Платформа**
- База — `fm1-base` из `..\overworld\src\base\` (копировать, не менять без нужды). Сборка/тулчейн/лимиты — как в `..\overworld\src\CLAUDE.md`.
- Проект: `..\deck\src\`. Структура — `DECK_SPEC.md` раздел 12. Сборка: `build.sh outrun`.
- Сразу `git init` в `deck\src` и коммит после каждой итерации (сообщение по-русски: «Итерация N: …»).

**Звук (подробно — OUTRUN_TAPE.md, раздел 2)**
- 9 движков: `KIT84 MONO JUNO PLUCK DX HERO TEXTURE PHASE ARCADE`. У каждого **3 главных параметра + MACRO**.
- «Аналоговый» дрейф голосов в JUNO/HERO/MONO/PLUCK — обязательно (это и есть синтвейвовый звук).
- Эффекты дорожки: CHORUS, TAPE, PHASER, BITCRUSH, DRIVE, FILTER, GATEVERB, SPRING, PUNCH, NITRO, PHONE. Посылы: ECHO, REVERB. Мастер: SIDECHAIN, VHS, SUNSET-макро, клиппер.
- Модуляторы: SWING (LFO), DICE, PEDAL, FOLLOW, TREMOLO.
- Сэмплов нет (памяти нет). Слои пресетов — опция, по умолчанию выкл.

**Удобство как у OP-1 (DECK_SPEC.md 1, 6.2a, 10)**
- 3 цветных энкодера: розовый / бирюзовый / оранжевый; параметр на экране нарисован цветом своей ручки.
- Страница SOUND = 4 вкладки `ENGINE / ENV / FX / MOD`, повторный тап FX листает. На вкладке ровно 3 параметра, каждый картинкой.
- **HOME + белая 1–16 = пресет** текущей дорожки. **Удерж. SAVE + белая 13–16 = сохранить пресет.** **HOME + чёрная 1–6 = выбрать дорожку.**
- Тоника — на странице KEYS (выдели ROOT, нажми клавишу).
- На PLAY: энкодер 1 = темп, 2 = MACRO дорожки, 3 = MOOD.
- Никаких «сохранить?» — автосохранение в тишине. Undo по истории.
- **МЕТРОНОМ обязателен** (DECK_SPEC 3.7): по умолчанию щёлкает при записи, счёт 1 такт, HOME+REC — вкл/выкл, не попадает в экспорт. Делать в итерации 2 вместе с записью, не откладывать.
- Секвенсоры на дорожку: STEP, LIVE, ENDLESS, ARP, DRIVE, FINGER, HOLD.

**Экран**
- Сцены PLAY — **готовые картинки** из `scenes/` (8 штук, по одной на метку части), код только оживляет их. Привязка к частям трека, вывески, эквалайзер — `OUTRUN_TAPE.md` 8.0 и `scenes/zones.json`.
- **Весь UI — минимализм OP-1** (DECK_SPEC 9.1, макеты `ui_concepts/Op1*.dc.html`): чёрный фон, тонкие линии, 3 цвета энкодеров + белый + серый, много воздуха. Лёгкий VHS/плёнка — только на странице PLAY поверх сцены. **Экран записи — анимированная кассета** (DECK_SPEC 9.1a, макет `ui_concepts/Tape.dc.html`).
- **Ни одна надпись не выходит за свою рамку** (подбор шрифта → сокращение → корень+цифра). Тест обязателен.
- Шрифты прошивки — только заглавные ASCII. Все надписи латиницей капсом.

## 3. Если в железе что-то не так — делай так (без вопросов)

| Если… | То… |
|---|---|
| кнопок/энкодеров меньше или они называются иначе, чем в таблице DECK_SPEC 10 | сделай ближайшее по смыслу, раскладку держи в одном файле `ui_map.c`, в отчёте покажи таблицу «кнопка → действие» |
| энкодеры нажимаются | нажатие = сброс параметра в дефолт |
| есть свободные кнопки/ручки | повесь на них VHS, SIDECHAIN, FILL — в этом порядке |
| нет датчика наклона | модулятор ELEMENT не делаем (и так не в плане) |
| 8 сцен по 240 не влезают во флеш | 120×2 для всех; если и так не влезает — 5 сцен (`city road grid vhsroom sunrise`), остальные метки частей показывают ближайшую по смыслу |
| CPU не тянет полный трек | порядок урезания: хвосты PLUCK/TEXTURE → слои → DRIFT → голоса JUNO 6→5→4 → анимация сцены замирает. Звук важнее картинки |
| USB-MIDI SysEx не проходит для экспорта | экспорт через MIDI-ноты + clock в реальном времени (Reaper пишет вживую), `.mid`-скрипт отложить |
| формат проекта OVERWORLD мешает | у DECK свой формат, своя магия `DECK`, свои адреса в data-области; OVERWORLD не трогать |

## 9. Качество звука — процедура (обязательна для любой кассеты)
Пользователь хочет **хорошие звуки** — это главный критерий. Для каждого движка и пресета:
1. Рендер WAV 44.1 кГц: одна нота, аккорд, короткая фраза (2–4 с на пресет) → `deck\src\out\sounds\<движок>\<пресет>.wav`.
2. Самопроверка скриптом по каждому WAV: нет щелчков на атаке/релизе (резкие скачки), нет цифрового алиасинга на высоких нотах, пик ≤ −1 dBFS, громкость пресетов выровнена (±2 dB между пресетами одного движка), нет DC-смещения, хвосты ревера не обрезаны.
3. Для OVERWORLD: сравнить с исходными звуками из `..\overworld\src` (тот же движок) — новое должно звучать **не хуже** старого; если хуже — вернуть старые параметры.
4. Если в `deck\refs\` лежат референсы (WAV/MP3 звуков, которые нравятся пользователю) — разобрать их спектр, атаку, затухание, яркость и подогнать ближайшие пресеты к этому характеру (не копировать, а приблизить). В отчёте написать, какой пресет к какому референсу подгонялся.
5. Сделать **`deck\src\out\listen.html`** — простая страница-плеер: список всех WAV по движкам с кнопками ▶, плюс демо-песня целиком. Пользователь будет слушать именно там.
6. Баланс микса демо-песни: ничего не «торчит», бас не гудит, пианино/главный инструмент слышно впереди.
