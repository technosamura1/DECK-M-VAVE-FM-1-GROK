# DECK — оболочка-операционка для M-VAVE FM-1

DECK — это «свой OP-1» на FM-1: секвенсор, 6 дорожек, аранжировка-трасса, умная клавиатура, микшер, экспорт в DAW.
Звуки, стиль и картинка приходят из сменной **кассеты**. Первая кассета — **OUTRUN** (синтвейв), её ТЗ лежит рядом в `OUTRUN_TAPE.md`.
Одна прошивка = DECK + одна кассета, кассета выбирается при сборке: `./build.sh outrun`.

---

## 0. Для Claude Code: с чего начать

1. **Референс** — готовый проект `..\overworld\src`. Та же база **fm1-base** (MPL-2.0, драйверы, загрузка, стор, хост-симулятор), то же железо.
   Новый проект: `fm1\deck\src\`. Скопируй оттуда `base/`, `tests/`-инфраструктуру и `build.sh`. Код приложения пиши заново по этому ТЗ.
2. **Сначала прочитай в OVERWORLD:**
   - `CLAUDE.md` — сборка, тулчейн, ограничения;
   - `app/app.h` — контракт приложения, объекты стора, адреса data-области;
   - `app/ui.c` — **реальные названия кнопок, энкодеров, клавиш FM-1**, светодиоды, пиксельный буфер с увеличением, отрисовка по очереди;
   - `app/dsp/ow.c` — голоса, блочный рендер, `shed` при перегрузе, лупер 24 PPQ, следование аккордам;
   - `app/project.c` — сохранение (магия, FNV-сумма, заголовок пишется последним);
   - `app/host.c` и `tests/` — сценарии, проверки `app_expect`, рендер WAV.
3. **Ограничения железа** (как в OVERWORLD):
   - только `float`, никакого `double`; математика через `fastmath.h`;
   - RAM (.data+.bss) ≤ 98304 байт; пул ≤ 344064; события и буферы — в пуле;
   - шрифты `FONT_T/M/L` — только заглавные ASCII 32..95. Все надписи латиницей, капсом;
   - экран 240×240 RGB565; 27 клавиш F3–G5 (16 белых, 11 чёрных);
   - CPU: худший случай не тяжелее OVERWORLD (~60 мкс на блок 128 на хосте); обязательный `shed()` при перегрузе — урезаются хвосты, а не ноты.
4. **На железе ничего не проверено.** Не трогай загрузчик, разметку флеша вне data-области, ничего, что может окирпичить.
5. Работай итерациями (раздел 13). После каждой: сборка, тесты, WAV-превью, PNG-скриншоты страниц из симулятора.

## 1. Философия (как в OP-1)

1. **Максимум 2 нажатия** до любой функции. Никаких вложенных меню.
2. **Одна кнопка — одно действие.** Удержание = второе действие, всегда по одной логике: «опасное» (очистить, undo) или «режим».
3. **Цветные энкодеры.** Каждый энкодер своего цвета: розовый, бирюзовый, оранжевый (порядок — как физически слева направо). На любой странице параметр нарисован цветом своей ручки. Не надо читать, что крутишь.
4. **Параметры — картинками, а не списками.** Каждый параметр имеет визуализацию (кассета задаёт рисунки, DECK даёт базовые).
5. **Каждое действие подтверждается** VHS-плашкой на 0.6 с: `TRACK 3 MUTED`, `PART B > CHORUS`, `UNDO`.
6. **Строка-подсказка** внизу каждой страницы: что делают кнопки здесь (`HOLD REC = CLEAR`).
7. **Всё отменяемо.** Undo по истории (≥ 16 шагов), redo.
8. **Никаких «сохранить?».** Всё сохраняется само.
9. **Звук не прерывается никогда** — ни при сохранении, ни при переключении страниц и частей.

## 2. Структура песни

### 2.1 Проекты
- 4+ проекта (песен) во флеше, в RAM загружен один. Переключение — страница PROJECT.
- Проект: темп, тональность, лад, настройки клавиатуры, 6 дорожек (звук, эффекты, микс), гараж частей, трасса.

### 2.2 Дорожки — 6 штук
- Каждая дорожка: **движок** (из кассеты) + **пресет** + **тип секвенсора** + **слот эффекта** + микс (громкость, пан, посылы в ECHO/REVERB, мьют/соло).
- Движок любой дорожки можно сменить на любой из кассеты. Кассета задаёт дефолтную раскладку (у OUTRUN: DRUMS, BASS, PAD, KEYS/ARP, LEAD, FX).
- Голоса — общий пул на все дорожки, распределение динамическое; при нехватке крадётся самый тихий/старый.

### 2.3 Части — «гараж»
- **8 частей** A..H. У части: имя-метка из списка (`INTRO VERSE PRE CHORUS DROP BRIDGE BREAK OUTRO`), цвет, длина 1/2/4/8/16 тактов.
- Внутри части у каждой дорожки свой клип; клип может быть короче части и крутится по кругу (полиметрия).
- Части пишешь когда угодно и в любом порядке.

### 2.4 Трасса — аранжировка
- Песня = **трасса**: цепочка до 64 блоков `{часть, повторы ×1..×8, трюки}`.
- Нарисована как ночное шоссе сверху/в перспективе: каждый блок — отрезок дороги цвета своей части, с подписью. Во время игры **по трассе едет машинка** и показывает позицию.
- Операции с блоками (как трюки с лентой у OP-1): вставить, удалить, дублировать, переставить, **вырезать/вставить**.
- **Трюки на блоке:** `HALF` (половинный темп нот), `DOUBLE`, `REVERSE` (ноты задом наперёд), `TRANSPOSE ±12`, `DROP` (выключить выбранные дорожки на этом блоке — для брейков и интро), `TAPESTOP` в конце блока.
- Режимы воспроизведения: **PART** (крутится текущая часть, переключение части — с конца такта) и **SONG** (едем по трассе).
- **Запись трассы вживую:** в режиме PART включаешь REC на странице ROAD — твои переключения частей пишутся в трассу.

### 2.5 Шаблоны песни
- При создании проекта можно выбрать шаблон: `EMPTY`, `POP` (INTRO 8 / VERSE 16 / CHORUS 16 / VERSE / CHORUS / BRIDGE 8 / CHORUS / OUTRO 8), `CLUB`, `AMBIENT`. Шаблон создаёт пустые части с метками и трассу из них.

## 3. Секвенсор

Разрешение 96 PPQ внутри (для свинга, рэтчетов, LIVE-записи), сетка ввода 16-е.

### 3.1 Типы секвенсора — у каждой дорожки свой
| Тип | Как работает |
|---|---|
| **STEP** | шаги 16-ми; курсор энкодером, клавиша ставит ноту/аккорд и двигает курсор; повтор той же ноты на шаге — стирает |
| **LIVE** | играешь на ходу, ноты квантуются (сила кванта 0–100 %), запись по кругу с дозаписью; каждый проход — отдельный слой для undo; запись стартует по первой ноте |
| **ENDLESS** | играешь ноты подряд без ритма, они крутятся по кругу в темпе с выбранным делением (как Endless у OP-1) |
| **ARP** | арпеджио из удерживаемых нот/аккорда: UP, DOWN, UPDN, RAND, ORDER, CHORD; 1/8, 1/16, 1/16T, 1/32; октавы 1–3; HOLD/латч |
| **DRIVE** | автопилот: партия генерится по стилю кассеты и текущей гармонии (раздел 5) |
| **FINGER** | живая игра готовыми рисунками (раздел 3.5) |
| **HOLD** | бурдон/дрон: зажатые ноты/аккорд держатся, пока не нажмёшь новые (как Hold у OP-1 Field); удобно держать пад левой и играть сверху |

### 3.2 Шаг хранит
нота(ы) / аккорд, VEL (тихо / норм / акцент, + точное значение), длина, **SLIDE**, **PROB** (100/75/50/25 %), **RATCHET** (×2/×3/×4), **микросдвиг** ±.

### 3.3 Барабанная дорожка (движок с флагом DRUM)
- Полосы = голоса кита (обычно 8). В STEP: 16 белых клавиш = 16 шагов текущей полосы, тап вкл/выкл шага; полоса выбирается чёрными клавишами или энкодером.
- В LIVE: белые клавиши = голоса кита, играешь пальцами.
- **FILL** (удержание): барабаны играют сбивку в стиле кассеты.

### 3.5 FINGER — живая игра рисунками (по мотивам Finger из OP-1, но удобнее)
- **Каждая белая клавиша = готовый рисунок на 1 такт** для этой дорожки: у DRUMS — грув, у BASS/KEYS/LEAD — фигура.
- Мелодические рисунки хранятся **в ступенях**, а не в нотах, и **идут по текущей гармонии**: сменил аккорд — фигура перестроилась.
- Держишь клавишу — рисунок играет (старт с ближайшей доли, квантуется); отпустил — тишина. Две клавиши разом — рисунки складываются (грув + сбивка).
- **LATCH:** тап = включить/выключить рисунок, играет, пока не выключишь.
- Раскладка 16 клавиш, слева направо: от простого к плотному; последние 3 — сбивки/брейки.
- **Чёрные клавиши** в FINGER = вариации текущего рисунка: HALF, DOUBLE, ACCENT, GHOST, SHIFT ±1/16.
- Рисунки задаёт кассета (16 на роль дорожки × на стиль DRIVE); **свой рисунок**: держишь SAVE и жмёшь белую клавишу — текущий клип такта записывается в этот слот.
- Работает с REC: всё, что играешь в FINGER, пишется в клип как обычные ноты (потом правишь в STEP).
- **Анимация:** на странице PLAY поверх сцены — пиксельные персонажи кассеты, играющие то, что выбрано (у OUTRUN — см. её ТЗ). Каждая дорожка в FINGER — свой персонаж.
- Это лучший режим для джема: зажал грув левой рукой, бас-фигуру правой, переключаешь — трек живой без записи.

### 3.6 Общее
- **SWING** 0–60 % на проект + на дорожку.
- **Запись движений ручек (motion):** покрутил параметр во время LIVE-записи — движение записалось в клип. На STEP: держишь шаг и крутишь ручку — **p-lock** этого шага (как Elektron).
- **Операции с клипом:** COPY / PASTE (между дорожками и частями), DOUBLE (удвоить длину с копией), CLEAR, TRANSPOSE (по ладу), **VARIATE** (синт слегка меняет ноты/ритм, сохраняя гармонию), HUMANIZE.
- **TAP TEMPO** (см. 3.7).

### 3.7 МЕТРОНОМ (обязательно, пользователь пишет всё живьём)
- **Режимы:** `REC` (по умолчанию — щёлкает только во время записи и счёта), `ALWAYS` (всегда, пока играет транспорт), `OFF`.
- **Счёт перед записью:** 1 или 2 такта (по умолчанию 1), щёлкает и на экране-кассете крупно 4…3…2…1. Запись начинается ровно с первой доли после счёта (или по первой ноте, если включено «старт по ноте»).
- **Звук:** акцент на первую долю (выше и громче), остальные доли тише. Тембры: `CLICK`, `WOOD` (деревяшка), `HAT`, `COWBELL`, `RIM`; у кассеты — свой по умолчанию (OUTRUN — `CLICK`, OVERWORLD — `WOOD`, мягкий).
- **Деление:** 1/4 (по умолчанию), 1/8, 1/16 тихими тиками — для медленных темпов.
- **Громкость** отдельная, **не попадает** в микс-запись, в STEMS и в экспорт `.mid`. Идёт прямо в выход, мимо ревера/эха/сайдчейна, с приоритетом голоса (никогда не крадётся `shed()`).
- **Свет:** на каждую долю мигает светодиод клавиши тоники (акцент — ярче); на экране — точка доли в шапке.
- **Быстрое управление:** **HOME + REC** — метроном вкл/выкл (плашка `METRO ON`/`OFF`); на экране-кассете энкодер 3 — громкость метронома; полные настройки — страница PROJECT → `METRO` (режим, счёт, тембр, деление, громкость).
- **TAP TEMPO:** HOME + PLAY тапами (3+ тапа), среднее, округление до целого BPM; плашка `TEMPO 92`.
- Настройки метронома — глобальные (не в проекте), сохраняются.
- Тест: при записи с метрономом записанные ноты не содержат кликов; в `.mid` нет дорожки метронома; клик не задерживается относительно сетки (сравнить позицию клика с тиком секвенсора в симуляторе, допуск ≤ 1 мс).
- Светодиоды клавиш: в STEP драмов — активные шаги + бегущий шаг; иначе — ноты лада, тоника ярче.

## 4. Клавиатура — страница KEYS

Узкие клавиши FM-1 неудобны, поэтому клавиатура «умная». Всё на одной странице, каждое поле — один энкодер.

| Поле | Значения |
|---|---|
| **LAYOUT** | `CHROMA` (обычная) / `SCALE` (лад на белых, по умолчанию) |
| **ROOT** | C … B — когда поле ROOT выделено, просто нажми клавишу нужной ноты (HOME + клавиша теперь = пресеты, см. 10) |
| **MODE** | MAJOR, MINOR, DORIAN, PHRYGIAN, LYDIAN, MIXOLYD, HARM MIN, MEL MIN, PENTA MAJ, PENTA MIN, BLUES |
| **WHITE** | `NOTES` / `CHORDS` |
| **BLACK** | `CHORDS` / `PERFORM` / `OCTAVE` |
| **CHORD** | тип аккорда (см. 4.3) |
| **QUALITY** | `DIATONIC` / `FIXED` |
| **VOICING** | CLOSE, OPEN, SPREAD, DROP2, POWER |
| **BASS** | вкл/выкл — добавить корень октавой ниже |
| **LEAD** | вкл/выкл — автоголосоведение |
| **STRUM** | 0–120 мс, вверх/вниз |
| **SPLIT** | вкл/выкл |
| **OCT** | −3 … +3 |

### 4.1 LAYOUT = SCALE
- **16 белых клавиш играют только ноты выбранного лада** от выбранной тоники, подряд вверх (≈ 2 октавы + ступени). Сфальшивить невозможно.
- В пентатонике и блюзе ступеней меньше — белые всё равно идут подряд по ступеням.

### 4.2 WHITE = CHORDS — аккорды на белых
- Выбрал тональность, включил `WHITE = CHORDS` — **каждая белая клавиша играет аккорд от своей ступени лада**.
- **QUALITY = DIATONIC:** качество аккорда берётся из лада (в C-мажоре на D — Dm7, на G — G7, если CHORD = 7). Уменьшённые — по настройке `DIM: SKIP/ALLOW` (SKIP заменяет на sus или соседний аккорд).
- **QUALITY = FIXED:** все клавиши играют аккорд одного типа (параллельные аккорды — чиллвейв, хаус). Тогда клавиша задаёт корень, тип — из поля CHORD.

### 4.3 Типы аккордов (CHORD)
Полный список, выбирается энкодером:
`TRIAD`, `5` (квинта/пауэр), `SUS2`, `SUS4`, `6`, `M6`(min6), `7`, `MAJ7`, `MIN7`, `DOM7`, `M7B5`, `ADD9`, `MADD9`, `9`, `MAJ9`, `MIN9`, `11`, `MIN11`, `13`, `7SUS4`, `QUARTAL` (кварты), `OCT` (октава), `CLUSTER`.
В режиме DIATONIC «7», «9», «11», «13» строятся по ладу; в FIXED — как названо.
Кассета может добавить свои (у OUTRUN — «жанровые» пресеты аккордов).

### 4.4 BLACK — что делают чёрные клавиши
- **CHORDS** — 11 готовых аккордов тональности: первые 7 — ступени лада (тип — из поля CHORD), последние 4 — «острые» заимствованные аккорды, набор задаёт кассета. Работает и когда белые = ноты: левой рукой аккорды на чёрных, правой мелодия на белых.
- **PERFORM** — перформанс-эффекты, пока держишь: STUTTER, TAPESTOP, REVERSE, FILTER UP, FILTER DOWN, KICK ONLY, ECHO THROW, BUILD, … (набор из кассеты).
- **OCTAVE** — октава вниз/вверх, NOTE REPEAT, FILL.

### 4.5 SPLIT
- Включён: **аккорды (чёрные, или белые в режиме CHORDS) пишутся в дорожку «гармонии»** (по умолчанию PAD, выбирается), **мелодия на белых — в текущую дорожку**. Обе руки сразу, всё раскладывается само.

### 4.6 Гармония проекта
- Последний сыгранный аккорд (с клавиш, из дорожки гармонии или из трассы) — **текущая гармония**. По ней идут DRIVE, ARP, бас-режимы кассеты.
- На экране крупно показывается, что звучит: `AM7`, `FMAJ9` (капсом — ограничение шрифта; минор помечать `M`, мажор-септ — `MAJ7`).

## 5. DRIVE — автопилот

- Тип секвенсора для любой дорожки. Генерирует партию по **стилю кассеты** для роли дорожки (DRUM / BASS / ARP / PAD / LEAD).
- **Гармония:** идёт по текущей гармонии (4.6). Если аккордов нет — берёт встроенную прогрессию кассеты для текущего лада. Сыграл аккорд — со следующей доли DRIVE на нём.
- **Ручки DRIVE** на дорожке: **ENERGY** (плотность), **STYLE**, **VARIATION**.
- Сбивки каждые 4/8 тактов; перед сменой части — подъём.
- **BAKE**: записать текущие 1/2/4 такта DRIVE в клип этой дорожки, тип секвенсора → STEP. Дальше правишь руками.
- DRIVE никогда не трогает дорожки, которые ты не перевёл в DRIVE.

## 6. Звук: движки, эффекты, модуляция

### 6.1 API движка (кассета реализует)
```c
typedef struct {
    const char *name;                 /* "JUNO" */
    uint8_t     flags;                /* POLY / MONO / DRUM */
    uint8_t     max_voices;
    uint8_t     nparams;              /* до 8; первые 3 — на цветных энкодерах на главной странице */
    const deck_param_t *params;       /* name, min, max, def, viz (рисунок), curve */
    void  (*voice_on)(void *v, int note, float vel, const float *p);
    void  (*voice_off)(void *v);
    int   (*voice_render)(void *v, float *out, int n, const float *p); /* 0 = голос освободился */
    uint16_t voice_size;              /* байт состояния голоса */
    uint8_t  cost;                    /* относительная цена голоса для бюджета CPU */
} deck_engine_t;
```
Конкретная форма — на твоё усмотрение, главное: **движки ничего не знают об UI и секвенсоре**, а DECK ничего не знает о том, как движок звучит.

### 6.2 Пресеты
- Банк на движок: 12 заводских + 4 пользовательских = **16 слотов = 16 белых клавиш** (как у OP-1).
- **Выбор пресета: HOME + белая клавиша** (на любой странице, для текущей дорожки); на вкладке ENGINE можно листать и энкодером. Имя пресета крупно на VHS-плашке.
- **Сохранить: удерживать SAVE и нажать белую клавиша 13–16** (заводские 1–12 защищены). Плашка `SAVED TO 14`.
- Каждый пресет хранит MACRO-маппинг (что крутит MACRO) — задаёт кассета.

### 6.2a Страница SOUND — 4 вкладки (как 4 страницы синта OP-1)
- `ENGINE` → `ENV` → `FX` → `MOD`. Переключение: **повторный тап FX** (кнопка страницы SOUND) листает вкладки по кругу; вкладки нарисованы сверху 4 цветными ярлыками, текущая подсвечена.
- На каждой вкладке ровно **3 параметра на 3 цветных энкодерах**, каждый — картинкой (кассета даёт рисунки, DECK — базовые полоски). Никаких списков и скролла.
- **MACRO** — одна главная ручка пресета; на странице PLAY живёт на энкодере 2.

### 6.3 Эффекты
- **Слот эффекта на дорожке** (из кассеты: CHORUS, TAPE, BITCRUSH, PHASER, DRIVE, FILTER, …).
- **Посылы:** общие **ECHO** (дилей синхро, на половинной частоте 16 бит, как плёночное эхо OVERWORLD) и **REVERB** (типы задаёт кассета).
- **Мастер:** слот эффекта кассеты (у OUTRUN — VHS, SIDECHAIN) + мягкий клиппер/лимитер.

### 6.4 Модуляция — картинками, как у OP-1
- 2 модулятора на дорожку. Типы: **SWING** (качели = LFO, синхро), **DICE** (кубик = рандом на долю/такт), **PEDAL** (педаль газа = плавный подъём за N тактов, сброс на смене части), **FOLLOW** (от громкости другой дорожки — пад «дышит» от бочки), **TREMOLO** (громкость по синхро-LFO). Вкладка MOD: TYPE / DEPTH / RATE (у FOLLOW вместо RATE — SOURCE: дорожка 1–6).
- Назначение одним жестом: **держишь кнопку модулятора и крутишь ручку параметра** — глубина назначена.

## 7. Микшер — страница MIX

- 6 вертикальных фейдеров, нарисованных как пульт 80-х; над каждым — мини-индикатор уровня.
- Энкодеры: громкость / пан / посыл выбранного канала; выбор канала — как выбор дорожки.
- Мьют/соло с клавиш (белые 1–6 = мьют, чёрные над ними = соло) — удобно для живого сведения.
- Мастер-громкость и мастер-эффект.

## 8. COM: экспорт и MIDI — страница PROJECT (как режим COM у OP-1)

### 8.1 EXPORT в .mid (главное)
- Кнопка `EXPORT`: синт отправляет песню по USB-MIDI SysEx-потоком (chunk'и с контрольной суммой).
- На ПК её принимает:
  - **`tools/deck_export.py`** (python, `mido`/`python-rtmidi`) — сохраняет `.mid`;
  - **`web/export.html`** (WebMIDI, Chrome) — то же самое из браузера, без установки.
- `.mid` Type 1: темп, тактовый размер, **6 дорожек с именами** (имя движка + пресет), **маркеры частей** (`INTRO`, `CHORUS` …) на таймлайне, все трюки трассы уже применены, p-lock/motion фильтра → CC74, громкость → CC7 (настраиваемо).
- Открываешь в Reaper → 6 MIDI-дорожек с маркерами частей.

### 8.2 Живой MIDI
- **MIDI OUT:** каждая дорожка на свой канал 1–6 (настраиваемо), + MIDI clock, start/stop. Reaper пишет все 6 дорожек сразу.
- **MIDI IN:** каналы 1–6 играют дорожки синта (Reaper может играть звуками FM-1). Clock in — опционально.

### 8.3 STEMS
- Режим `STEMS`: после счёта песня проигрывается 6 раз подряд, каждый раз соло одной дорожки (+ 1 раз полный микс), с паузой-маркером (щелчок) между проходами. Записываешь выход синта через аудиокарту одним дублем и режешь в Reaper по щелчкам.

## 9. Экран и интерфейс

### 9.1 Стиль — красиво и в одном стиле, по мотивам OP-1 (ГЛАВНОЕ ДЛЯ ВСЕГО UI)
**Не крайний минимализм**, а единый аккуратный стиль: всё выглядит как одно устройство. Правила ниже — ориентир; если что-то становится красивее с лёгким цветом/свечением/иконкой — можно, лишь бы во всех страницах одинаково.
Референс: `ui_concepts/Op1Sound.dc.html`, `Op1Seq.dc.html`, `Op1Keys.dc.html`, `Op1Mix.dc.html`. Старые макеты (`Sound/Seq/Keys/Song.dc.html` с VHS-рамками) — **отменены** как стиль, по ним смотреть только содержание.
- **Фон чёрный** `#000`. Никаких рамок, плашек, теней, градиентов, шашечек, сканлайнов на рабочих страницах.
- **Цвета только по смыслу:** 3 цвета энкодеров (задаёт кассета: OUTRUN — розовый `#FF3D8B` / голубой `#00D8FF` / оранжевый `#FF9A1F`; OVERWORLD — зелёный / голубой / жёлтый) + белый `#E8E8E8` + 2 серых (`#6A6A6A` подписи, `#2A2A2A` линии/неактивное). Больше цветов на рабочих страницах нет.
- **Тонкие линии (1 px), простая геометрия:** круги, дуги, прямые. Шаги секвенсора — точки (вкл = крупная точка, выкл = мелкая серая). Фейдеры — линия + короткая планка. Клавиатура — контуры.
- **Много воздуха.** Отступы ≥ 12 px (в координатах экрана 240 — ≥ 6). На странице максимум: строка-шапка (мелко, серым) + одна большая вещь (имя пресета / аккорд / сетка / фейдеры) + 3 цветных значения внизу.
- **Большое — тонким, маленькое — серым.** Главное значение крупно и светло (имя пресета, аккорд), подписи мелко и серым. Шрифт — Terminus из прошивки, капсом, без жирного.
- **3 цветных значения внизу на каждой странице** — всегда в одном месте, всегда в порядке энкодеров: точка цвета энкодера, подпись, значение. Это и есть «OP-1»: глаз всегда знает, где что крутится.
- **Картинка параметров** (вкладка ENGINE) — простая цветная геометрия: срез = круг-солнце за линией горизонта (цвет энк. 1), хорус = две пилы со сдвигом (энк. 2), релиз = линия огибающей (энк. 3). Двигается вместе с ручками, плавно.
- **Шапка/подвал** — без фона, просто текст.
- **Сцены-картинки и сад — только на странице PLAY** (это «арт»-экран кассеты). VHS/плёнка — только там и только лёгкие. Все остальные страницы — чистый минимализм.
- Переходы страниц — мгновенно или короткий сдвиг 3–4 кадра, без помех.

### 9.1a Экран записи — КАССЕТА (как лента у OP-1; исключение из минимализма)
Референс: `ui_concepts/Tape.dc.html` (кассета в стиле Maxell, бобины крутятся, под ней 6 дорожек-лент). Это «арт»-экран, как сцены PLAY: его рисуем детально, остальное — минимализм.

**Когда появляется:** автоматически, как только нажат REC (LIVE-запись, ENDLESS, запись трассы, запись движений ручек). Отпустил запись — через 1 такт возврат на страницу, с которой пришёл. Вызвать вручную: удерж. REC на странице PLAY.

**Что показывает и что делает:**
- **Бобины крутятся со скоростью темпа** (оборот = 1 такт). Стоп — стоят. Перемотка/переход части — крутятся быстро с коротким звуком перемотки (опционально).
- **Намотка ленты = позиция в песне:** левая бобина толстая в начале и худеет, правая растёт. В режиме PART — позиция внутри части (по кругу), в режиме SONG — по всей трассе.
- **Записывающая головка горит красным** и мигает на каждой записанной ноте; `● REC` в шапке мигает.
- **Наклейка кассеты:** имя проекта и `SIDE A` (части A–D) / `SIDE B` (E–H); полоса с цветом кассеты и темпом.
- **6 дорожек-лент под кассетой** = 6 дорожек проекта: мини-ролл нот текущей части, курсор бежит по ним. Записываемая дорожка подсвечена, **ноты текущего прохода — красные**, прошлых проходов — цветом дорожки. Счётчик `PASS N`.
- **Действия на этом экране:** REC — новый проход поверх (overdub), удерж. EDIT — отменить последний проход (лента «перематывается назад» и красные ноты исчезают), энкодер 1 — квантование записи, энкодер 2 — какая дорожка пишется, энкодер 3 — громкость метронома.
- **Счёт перед записью:** 1 такт — бобины стоят, на наклейке крупно 4…3…2…1, потом поехали.
- Кассета берёт цвета/надписи из темы кассеты: OUTRUN — тёмный корпус, радужная полоса 80-х; OVERWORLD — светлый корпус, тёплая наклейка, надпись `OVERWORLD`.
- Анимация бобин — поворот готовой маленькой спрайт-картинки хаба (8 фаз), не вращение в реальном времени; лента и намотка — простые круги.

### 9.2 Страницы
| Страница | Что на ней |
|---|---|
| **REC** | экран-КАССЕТА (9.1a): появляется сам при записи |
| **PLAY** | сцена кассеты на весь экран (у OUTRUN — картинка, сменяется по частям трека); аккорд и уровни дорожек живут ВНУТРИ сцены (вывеска, окна-эквалайзер), поверх — только тонкие шапка и подвал |
| **SEQ** | клип текущей дорожки: сетка шагов (STEP), пиано-ролл-мини (LIVE/ENDLESS), настройки ARP/DRIVE |
| **SOUND** | 4 вкладки ENGINE / ENV / FX / MOD (6.2a); имя пресета крупно; 3 параметра цветными рисунками |
| **MIX** | микшер (7) |
| **ROAD** | трасса (2.4) + гараж частей |
| **KEYS** | настройки клавиатуры (4) |
| **PROJECT** | проекты, шаблоны, темп/свинг, EXPORT, STEMS, MIDI, CPU %, версия |

- **Шапка** (всегда): `▶/●/■`, часть (буква+цвет), такт.доля, темп, 6 точек-дорожек (выбранная подсвечена, мьют — потушена).
- **Подвал:** строка-подсказка.
- Отрисовка по очереди: сцена и шапка/подвал в разные кадры, как в OVERWORLD. Пиксельные сцены — логический буфер с увеличением ×3.

## 10. Управление (предложение — сверить с реальными кнопками в `overworld/src/app/ui.c`)

**HOME = SHIFT.** Четыре кнопки инструментов — это «мод-кнопки» страниц, как у OP-1.

| Кнопка | Тап | Удержание / с HOME |
|---|---|---|
| **FX** | страница SOUND; повторный тап — следующая вкладка ENGINE→ENV→FX→MOD | — |
| **SEL** | страница SEQ | удерж.: выбор типа секвенсора |
| **ENV** | страница ROAD | удерж.: гараж частей |
| **LFO** | страница MIX | удерж.: модуляторы дорожки |
| **PLAY** | старт/стоп | HOME+PLAY тапами: TAP TEMPO; удерж. PLAY: режим PART/SONG |
| **REC** | запись (по типу секвенсора), со счётом и метрономом | удерж. 1 с: очистить клип; **HOME+REC: метроном вкл/выкл** |
| **GLO** | следующая дорожка | HOME + чёрная 1–6 (первые 6 чёрных слева): выбрать дорожку; удерж. GLO: мьют |
| **ARP** | следующая часть (с конца такта) | удерж. + белая A..H: перейти к части |
| **SEQ** | FILL (пока держишь) | HOME+SEQ: BAKE |
| **EDIT** | страница KEYS | удерж.: UNDO; HOME+EDIT: REDO |
| **SAVE** | страница PROJECT (COM) | удерж. SAVE + белая 13–16: сохранить пресет дорожки |
| **HOME** | страница PLAY | SHIFT; **HOME + белая 1–16: пресет текущей дорожки** (как Shift+клавиша у OP-1); HOME + чёрная 1–6: дорожка |

| Энкодер | Цвет | Функция |
|---|---|---|
| 1 (SELECT) | розовый | параметр 1 страницы (на PLAY — темп) |
| 2 (ALGO) | бирюзовый | параметр 2 (на PLAY — **MACRO** текущей дорожки) |
| 3 (PRESET) | оранжевый | параметр 3 (на PLAY — MOOD кассеты) |

- Если энкодеры нажимаются: нажатие = сброс параметра в дефолт.
- Если на FM-1 есть контролы, не задействованные в OVERWORLD, — предложи, что на них повесить, и опиши в `CLAUDE.md`.
- Раскладка — первая версия, после проверки на железе будем менять. Держи её в одной таблице в коде (`ui_map.c`), чтобы менять было легко.

## 11. Хранение

- Проекты — в data-области (как части OVERWORLD): заголовок с магией `DECK` + версия формата + FNV-сумма, **заголовок пишется последним**.
- Автосохранение: через 3–5 с тишины после изменений и при стопе; **никогда во время воспроизведения** (стирание флеша глушит звук).
- Цели по объёму (проверить, что влезает): ≥ 4 проекта, ≥ 3000 нот на проект, motion-данные. Если не влезает — уменьшить проекты, не ноты.
- Формат версионируется: новая прошивка читает старые проекты или честно начинает с пустого (без мусора).
- Пользовательские пресеты — отдельный объект стора.

## 12. Кассеты: как подключаются

```
deck/src/
  base/              # fm1-base
  deck/              # оболочка: seq, song, keys, ui, mix, export, store, api
  tapes/
    outrun/          # кассета: engines/, fx/, presets.c, drive.c, theme.c, moods.c, tape.c
  tests/
  tools/deck_export.py
  web/export.html
  build.sh           # ./build.sh outrun
```
- Кассета экспортирует одну структуру `deck_tape_t`: имя, движки, пресеты, эффекты, стили DRIVE, «острые» аккорды, перформанс-эффекты, MOOD-ы, тема (палитра, сцены, сплэш, рисунки параметров), демо-проект.
- Кассета **не знает** о секвенсоре и страницах. DECK **не знает** о звуке и рисунках сцен.
- В `CLAUDE.md` — раздел «Как сделать новую кассету» (чек-лист).
