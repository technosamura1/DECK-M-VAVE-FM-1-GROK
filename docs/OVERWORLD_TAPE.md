# OVERWORLD — кассета 2 для DECK (лоу-фай эмбиент в духе музыки C418)

Тихое пианино, тёплые пады, стеклянные колокольчики, пыльные лоу-фай барабаны, шум дождя и винила. Музыка, под которую строишь, гуляешь и засыпаешь.
Кассета реализует API из `DECK_SPEC.md` (раздел 12). Папка: `tapes/overworld/`. Сборка: `build.sh overworld`.
**Делать ПОСЛЕ финала OUTRUN**, отдельной командой. Основа звука — готовый движок из `..\overworld\src\app\dsp\ow.c` (пиано, пад, колокол, бас, ревер, плёночное эхо) — перенести в API движков DECK, не писать заново.

Главное ощущение: **много воздуха, мало нот, всё чуть «плывёт».** Если сомневаешься — тише, медленнее, реже.

## 2. Движки (у каждого 3 главных + MACRO, как в OUTRUN)

| Движок | Что это | Главные 3 | MACRO |
|---|---|---|---|
| `FELT` | **пианино с войлоком** — главный инструмент. Основа: FM-пиано OVERWORLD (затухающий индекс, унисон-струна, шум молоточка, двухстадийное затухание, демпфер, педаль). Плюс «войлок»: срез верха, мягкая атака, слышный механический стук клавиши | TONE / FELT / DECAY | `MEMORY`: войлок + плёнка + ревер — «старое воспоминание» |
| `TINE` | лоу-фай электропиано (Rhodes-подобное, FM 2-оп) с тремоло | TINE / TREMOLO / DRIFT | `DUSTY`: тремоло + сатурация + срез верха |
| `AIRPAD` | тёплый пад OVERWORLD: 2 детюненные пилы → мягкий ФНЧ, очень медленная атака, «дыхание» фильтра | BRIGHT / SWELL / AIR | `SKY`: раскрытие + шиммер-ревер |
| `GLASS` | колокол OVERWORLD: GLASS / CELESTA / MARIMBA / MUSIC BOX (2-оп FM) | TYPE / DECAY / SHINE | `SNOW`: длинный хвост + эхо + высокая октава |
| `KALIMBA` | щипковый металл/дерево, физ. модель (короткая струна-«язычок») | TONE / DECAY / WOOD | `CAMPFIRE`: дерево + тёплый ревер |
| `SOFTBASS` | синус + немного 2-й гармоники, мягкий щипок, как контрабас без грязи | TONE / PLUCK / GLIDE | `DEEP`: суб + длина |
| `DUSTKIT` | лоу-фай барабаны: мягкая бочка, снейр-щётка, римшот, шейкер, закрытый хет, «пыльный» клэп, перкуссия-дерево; всё через 12 бит + ФНЧ | TUNE / DECAY / DUST | `TAPE`: биты + насыщение + свинг-ощущение |
| `WORLD` | звуки мира (шумовой синтез): дождь, ветер, огонь костра, ручей, пещерные капли, сверчки, птицы, океан, гроза вдалеке, шаги по снегу | TYPE / AMOUNT / TONE | `WEATHER`: плотность + удалённость |

**«Аналог» и «плёнка» обязательны:** дрейф голосов (как в OUTRUN, но медленнее), у FELT/TINE/GLASS лёгкий wow (0.3–0.6 Гц) по умолчанию. Гуманизация тайминга и силы нажатия в LIVE/ENDLESS/TOMBOLA — по умолчанию 25 % (параметр кассеты `HUMAN`).

## 3. Эффекты
- **Дорожка:** `VINYL` (треск + шип + лёгкий срез), `TAPE` (wow/flutter + сатурация + «усталость» верха), `LOFI` (биты + частота дискретизации + ФНЧ), `CHORUS`, `FILTER`, `TREMOLO`, `SPRING`.
- **Посылы:** ECHO — плёночное эхо OVERWORLD (половинная частота, 16 бит); REVERB — плейт Dattorro из OVERWORLD, типы `ROOM` (уютный), `HALL`, `CAVE` (длинный, тёмный, с ранними отражениями), `SHIMMER` (+октава, для неба/снега).
- **Мастер:** `DUST` (одна ручка: винил + плёнка + срез верха — 0 чисто, 100 «кассета из детства»), `SLEEP` (макро: всё темнее, медленнее эхо, длиннее ревер — для аутро), мягкий лимитер. **Сайдчейн — лёгкий** (по умолчанию 15 %, только на пад от бочки).

---

## 4. Гармония
- Лады: MAJOR, LYDIAN (главная краска C418), DORIAN, MIXOLYD, MINOR, PENTA MAJ.
- По умолчанию **WHITE = CHORDS, CHORD = MAJ7/MIN9 (DIATONIC), VOICING = OPEN, STRUM = 40 мс**: нажал белую — тихий «размазанный» аккорд, как у пианиста.
- **«Острые» аккорды (4 последние чёрные):** в мажоре — **iv** (минорная субдоминанта — «щемящий» аккорд C418), **♭VII**, **II** (лидийская), **IVmaj9 над корнем** (подвешенность); в миноре — **IV**, **♭VI add9**, **♭III maj7**, **v9**.
- **Пресеты аккордов:** `MEADOW` (MAJ7/ADD9, OPEN), `LOFI` (MIN9/MAJ9/7, DROP2 — джазовые ii–V), `CAVE` (SUS2/5, широкие), `SNOW` (ADD9 высоко, SPREAD), `NIGHT` (MIN11, мягко).
- **Прогрессии DREAM:** `I–IVmaj7–vi–IV`, `I–iii–IV–iv` (C418), `IVmaj7–I–vi–V`, `ii9–V7–Imaj9–vi9` (лоу-фай), `Imaj7–II–IVmaj7–I` (лидийская), долгие — 2 такта на аккорд.

---

## 5. DREAM — автопилот (это DRIVE оболочки, со стилями кассеты)
Логика — из DREAM OVERWORLD: фразовые мотивы, ступени аккорда, «вопрос-ответ» на то, что ты сыграл, виртуальная педаль, разброс тайминга. Уменьшённые аккорды выкидывать.

| STYLE | DRUMS | BASS | PIANO/KEYS | BELLS | NATURE |
|---|---|---|---|---|---|
| **C418** | нет | редкие длинные ноты | **редкие фразы 2–4 ноты, паузы по 1–2 такта**, иногда аккорд снизу | изредка ответ | да |
| **LOFI** | бум-бэп 70–85 BPM, свинг 58 %, ленивый снейр, шейкер | корень–квинта, джазовые проходы | аккорды 7/9 на «и» доли, лёгкий страм | — | дождь/винил |
| **AMBIENT** | нет | бурдон | пад + редкие аккорды | TOMBOLA | да |
| **CAMPFIRE** | перкуссия-дерево, шейкер | щипок | KALIMBA-арп | — | огонь, сверчки |

- **ENERGY** — плотность. 0 — почти тишина (только мир + одна нота в 2 такта), 100 — лоу-фай бит с полной гармонией.
- Каждые 8 тактов DREAM **уходит в тишину на такт** (C418 дышит паузами). Отключаемо.
- Ты играешь — DREAM отвечает фразой через 1–2 такта (call & response из OVERWORLD).

## 6. TOMBOLA — физический секвенсор (новый тип секвенсора, кассета включает его в DECK)
Как Tombola в OP-1, но для эмбиента:
- На экране медленно вращается **пиксельный шестиугольник-«барабан»**. Каждая сыгранная нота падает внутрь шариком (до 12 шариков).
- Удар шарика о стенку = нота (высота шарика = его нота, сила = скорость удара).
- Ручки: **SPIN** (скорость вращения), **GRAVITY**, **BOUNCE** (упругость). MACRO `CHAOS` — всё вместе.
- **QUANT** — удары притягиваются к сетке 1/8 или 1/16 (по умолчанию 1/8 с 30 % силы) — чтобы не разваливался ритм с бочкой.
- Удержание REC — вытряхнуть все шарики.
- Красиво для колокольчиков и калимбы: бесконечная, никогда не повторяющаяся мелодия из твоих нот.
- Физика — целочисленная, ≤ 2 % CPU; экран TOMBOLA — отдельный вид на странице SEQ.

## 7. FINGER-рисунки (лоу-фай)
DRUMS: 13 грувов (от «только шейкер» до полного бум-бэпа) + 3 сбивки (римшот-ролл, стоп, «пластинка тормозит»). BASS/KEYS — фигуры по ступеням, ленивые, с опозданием на 10–20 мс.

## 8. Перформанс-эффекты (BLACK = PERFORM)
`TAPESTOP`, `REWIND` (звук перемотки + скретч), `VINYL STOP`, `LOW PASS` (как будто музыка за стеной), `RAIN UP`, `DREAM OFF/ON`, `HALF TIME`, `ECHO THROW`, `MUTE DRUMS`, `SLEEP`, `REVERSE`.

## 10. Экран: сад с цветами из прошлой OVERWORLD
**Берём сад из `..\overworld\src\app\ui.c` как есть** — это уже сделано и нравится пользователю: пиксельный луг, цветы по инструментам раскрываются по мере игры, грибы для баса, частицы (дождь, снег, светлячки, искры), смена дня и ночи, солнце/луна, облака, пчела показывает позицию лупа, биомы. Перенести в DECK как тему кассеты, **ничего не придумывать сверху** без запроса пользователя.
Минимальные доработки только для стыковки с оболочкой:
- цветы растут от нот **всех 6 дорожек** (вид цветка = движок дорожки, как в OVERWORLD = инструмент);
- MOOD кассеты = биом сада (как сцены OVERWORLD: PLAINS / RAIN / CAVE / SNOW / OCEAN / NIGHT + CAMPFIRE, STUDY → ближайший существующий биом);
- день/ночь — как в OVERWORLD;
- сад сохраняется в проекте (как было);
- название аккорда и части — в шапке, на самом лугу текста нет;
- TOMBOLA на странице SEQ — свой вид (шестиугольник/банка), на сад не влияет.
Палитра UI и шрифты — как в OVERWORLD. Вместо VHS — без эффекта или лёгкое зерно (если не тормозит).

## 11. Сплэш
Сплэш из прошлой OVERWORLD как есть.

## 12. Демо-проект `FIRST LIGHT`
PLAINS, 76 BPM, до мажор/лидийский: INTRO (только пиано C418-фразы + птицы, 8 т.) → PRE (пад входит, 8) → VERSE (бит LOFI тихо + бас, 16) → CHORUS (полная гармония `I–iii–IV–iv`, колокола TOMBOLA, 16) → BRIDGE (без барабанов, SNOW, 8) → BREAK (костёр, калимба, 8) → OUTRO (пиано одно, SLEEP-макро, 8).

## 13. Готовность
- WAV каждого движка (все пресеты по 2 с), WAV демо-песни, бенчмарк CPU.
- Звук проверить на «C418-тест»: одна фраза FELT в PLAINS должна звучать мягко, без металла и щелчков, с хвостом.
- PNG: все страницы с палитрой кассеты, экран TOMBOLA, сад в нескольких биомах днём и ночью.
